Knowledge Base Service

Спецификация взаимодействия микросервиса базы знаний, поиска, тематических блоков и аналитических статей.

Базовый адрес API
http://localhost:8003
Swagger UI документация
http://localhost:8003/docs
Схема авторизации
X-Admin-Key (управление) / Публичный (чтение)
Пагинация и поиск
Query: page, page_size, limit, offset, block, q

Вводная информация:

Тематические блоки (block)
1. Гидратация и питьевой режим (расчёт нормы воды, электролиты, чай/кофе)
2. Стандарты, маркировка и законы (FDA, регламенты ТР ТС, калорийность порции/100г)
3. Нутриенты, витамины и макроэлементы (роль БЖУ, микроэлементы, дефициты)
4. Методы взвешивания, расчёта и учёта (сырой/варёный вес, кости, уварка/ужарка)
5. Калории, энергетический баланс и метаболизм (BMR, дефицит, профицит, алкоголь)
6. Общие вопросы питания, физиологии и психологии (срывы, насыщение, режим дня)
Категории статей (category)
general — общие вопросы физиологии и пищевого поведения
calories — калорийность, энергетическая ценность и BMR
nutrients — макронутриенты (белки, жиры, углеводы) и микроэлементы
methods — алгоритмы расчёта сложных блюд и взвешивания
standards — нормативные акты, стандарты маркировки и регуляторы
hydration — нормы потребления жидкости и баланс воды
Полнотекстовый поиск (AND-логика)
Поиск выполняется по всем ключевым словам: статья включается в выдачу, только если каждое переданное слово встречается хотя бы в одном из полей: вопросе (question), ответе (answer), тегах (tags) или блоке (block).
Регистр символов игнорируется (поиск регистронезависимый).
Пагинация через поля (Query Params)
Поддерживаются параметры page (начиная с 1) и page_size (1-100, по умолчанию 20), а также альтернативные limit и offset.
Эндпоинт GET /kb возвращает плоский массив, а метаданные отдаются в заголовках: X-Total-Count, X-Page, X-Page-Size, X-Total-Pages, X-Has-Next, X-Has-Prev.
Формат ответов: Плоский список vs JSON-объект
• GET /kb и GET /kb/search возвращают массив [...] (100% обратная совместимость с мобильным приложением).
• GET /kb/paginated возвращает структурированный JSON-объект { items: [...], total, page, page_size, total_pages, has_next, has_prev }, если клиенту так удобнее парсить стейт.
Административный доступ (X-Admin-Key)
Все методы модификации базы знаний (POST /kb, PATCH /kb/{aid}, DELETE /kb/{aid}) требуют передачи HTTP-заголовка X-Admin-Key: tester.
При отсутствии заголовка возвращается 422 Unprocessable Entity, при неверном значении ключа — 403 Forbidden.

GET /kb
Публичный

Получить статьи базы знаний (с фильтрацией по блоку, категории, ключевым словам и пагинацией).

Возвращает плоский массив статей. Позволяет гибко комбинировать параметры: выбрать конкретный блок вопросов, отфильтровать по категории, выполнить поиск ключевых слов и ограничить страницу выдачи.

Метаданные пагинации возвращаются в HTTP-заголовках: X-Total-Count, X-Page, X-Page-Size, X-Total-Pages, X-Has-Next, X-Has-Prev.

Параметры строки запроса (Query Params)

block string Опционально Фильтр по точному названию блока (например, Гидратация и питьевой режим)
q string Опционально Ключевые слова для поиска по вопросу, ответу, тегам и блоку
category string Опционально Фильтр по коду категории (general, calories, nutrients, methods, standards, hydration)
page integer Опционально Номер страницы (начиная с 1). По умолчанию 1 (если указан page_size)
page_size integer Опционально Количество статей на страницу (от 1 до 100, по умолчанию 20)
limit integer Опционально Количество возвращаемых записей (альтернатива page_size, до 1000)
offset integer Опционально Смещение записей от начала (по умолчанию 0)

GET /kb/search
Публичный

Полнотекстовый поиск по вопросам, ответам, тегам и блокам с поддержкой пагинации.

Поиск выполняется по всем переданным словам (логика AND): статья попадает в результат, только если каждое слово встречается хотя бы в одном из полей. Пример: q=калорийность упаковка найдёт статьи, содержащие оба слова.

q string Обязательно Поисковый запрос (ключевые слова через пробел, минимум 1 символ)
block string Опционально Ограничить поиск конкретным тематическим блоком
category string Опционально Ограничить поиск категорией
page integer Опционально Номер страницы результатов (начиная с 1)
page_size integer Опционально Количество результатов на странице (от 1 до 100)

POST /kb
X-Admin-Key: tester

Создание новой статьи в базе знаний.

Метод защищён административным ключом. Требуется передавать заголовок X-Admin-Key.

Параметры заголовков (Headers)
Заголовок Тип Обязательность Описание

question string Обязательно Длина от 3 до 1000 символов. Текст вопроса статьи

category string Опционально (по умолч. "general") Код категории (general, calories, nutrients, methods, standards, hydration)
block string | null Опционально Название тематического блока (до 128 символов)
tags string | null Опционально Ключевые слова через запятую (до 512 символов)
