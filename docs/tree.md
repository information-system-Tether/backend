## Назначение корневых директорий

| Директория | Назначение |
| :--- | :--- |
| `/.github/workflows` | Конфигурация сценариев автоматической проверки кода и тестов при публикации изменений в репозиторий. |
| `/db` | Конфигурация контейнера базы данных PostgreSQL 18 с сохранением данных в volume `pgdata`. |
| `/pg` | Конфигурация контейнера веб-панели pgAdmin 4 для работы с базой данных PostgreSQL через браузер на порту 8080. |
| `/docs` | Папка документации: руководства по запуску, дерево структуры, реестр вопросов и документация сервисов в папке `service/`. |
| `/pyth` | Каталог с исходным кодом микросервисов: `auth`, `diary`, `kb`, общим списком библиотек `requirements.txt` и файлом сборки `docker-compose.yml`. |

## Корневые файлы проекта

- **`docker-compose.yml`**: Главный файл запуска контейнеров. Подключает настройки из папок `./db`, `./pyth` и `./pg`, что позволяет запускать всю систему одной командой `docker compose up -d`.
- **`run_backend.py`**: Скрипт запуска всех микросервисов без Docker на базе локального файла SQLite. Создает таблицы, наполняет начальными данными и запускает серверы.
- **`tether.db`**: Файл базы данных SQLite, который используется при работе скрипта `run_backend.py`.
- **`requirements-dev.txt`**: Список библиотек для локальной разработки и запуска тестов (включает `pytest` и `httpx`).
- **`.gitignore`**: Список файлов и папок, которые не должны попадать в репозиторий Git (временные файлы, базы данных, кэш).

## Ознакомительное описание модулей по сервисам

> Подробное техническое описание каждого файла `.py`, классов, функций, параметров и эндпоинтов представлено в соответствующих документах в папке `docs/service/`.

### 1. Сервис Auth (`pyth/auth`)
*Подробный документ:* [**docs/service/auth.md**](file:///D:/Tether/docs/service/auth.md)
- `main.py` — запуск FastAPI, CORS, обработка ошибок валидации.
- `models.py` — таблицы `auth` (пользователи) и `revoked_tokens` (отозванные токены).
- `routes.py` — эндпоинты `/auth/register`, `/auth/login`, `/auth/me`, `/auth/logout`, `/health`.
- `schemas.py` — Pydantic-схемы валидации регистрации, входа и профиля.
- `service.py` — бизнес-логика учетных записей и отзыва токенов.
- `security.py` — хеширование bcrypt, выпуск и проверка токенов JWT.
- `lim.py` — Rate Limiter (ограничение частоты запросов для защиты от брутфорса).
- `config.py` — чтение параметров окружения (JWT_SECRET_KEY, DATABASE_URL).
- `database.py` — подключение к БД и сессии SQLAlchemy.
- `testuser.py` — скрипт создания тестового пользователя `tester`.

### 2. Сервис Diary (`pyth/diary`)
*Подробный документ:* [**docs/service/diary.md**](file:///D:/Tether/docs/service/diary.md)
- `main.py` — запуск FastAPI, вызов миграций и сидирования продуктов.
- `calculation.py` — расчет BMR, TDEE, коридора калорий, макронутриентов, нормы воды и шагов.
- `models.py` — таблицы листов (`diary_sheets`), записей (`entries`), профиля (`bio`), продуктов (`base_products`, `user_products`) и избранного (`favorites`).
- `routes.py` — эндпоинты листов по датам, записей приемов пищи, профиля здоровья, каталогов продуктов и аналитики.
- `services.py` — бизнес-логика пересчета граммовок, суммирования за день и расчета статистики за неделю.
- `schemas.py` — Pydantic-схемы антропометрии, порций и отчетов.
- `security.py` — проверка входящего токена JWT и извлечение `user_id`.
- `baseproducts.py` — начальный справочник продуктов с проверенным КБЖУ.
- `database.py` — сессии БД и функция `addcols()` для автоматического добавления колонок.
- `config.py` — конфигурация сервиса дневника.
- `init_db.py` — первичная инициализация таблиц и продуктов.

### 3. Сервис KB (`pyth/kb`)
*Подробный документ:* [**docs/service/kb.md**](file:///D:/Tether/docs/service/kb.md)
*Реестр вопросов базы знаний:* [**docs/rosterofquestions.md**](file:///D:/Tether/docs/rosterofquestions.md)
- `main.py` — запуск FastAPI, экспорт заголовков пагинации.
- `models.py` — таблица статей `kb_articles` (вопрос, ответ, категория, блок, теги).
- `routes.py` — эндпоинты выдачи статей, пагинации, поиска по словам и CRUD.
- `services.py` — логика полнотекстового поиска с оператором AND по ключевым словам.
- `seed_kb.py` — массив из 113 готовых экспертных статей по 6 тематическим блокам.
- `schemas.py` — Pydantic-схемы для статей и метаданных пагинации.
- `security.py` — проверка ключа `X-Admin-Key` для редактирования базы знаний.
- `config.py` — настройки сервиса базы знаний.
- `database.py` — сессии SQLAlchemy.
- `init_db.py` — скрипт инициализации таблиц и загрузки статей.
- `__init__.py` — маркер пакета Python.

## Схема взаимодействия компонентов

```text
[Клиент: мобильное приложение или браузер]
│
├─ 1. Вход: POST /auth/login (логин и пароль)
│  └─ [Auth Service (порт 8001)]
│     └─ Проверка пароля в базе данных
│
├─ 2. Возврат токета JWT с идентификатором пользователя
│
└─ 3. Запрос с заголовком: Authorization: Bearer <токен>
   │
   ├─ [Diary Service (порт 8002)]
   │  ├─ Проверка подписи токена
   │  ├─ Извлечение user_id
   │  └─ Работа с листами питания и нормами КБЖУ в базе данных
   │
   └─ [KB Service (порт 8003)]
      └─ Поиск и чтение справочных статей в базе данных
```
