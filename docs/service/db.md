# Сервис базы данных DB (PostgreSQL)

## 1. Где находится

- **Каталог:** `db/`
- **Файл конфигурации:** `db/docker-compose.yml`
- **Имя сервиса в Docker Compose:** `dbpostgres`
- **Имя контейнера:** `db`
- **Порт СУБД:** `5432` (проброшен наружу `5432:5432`)
- **Базовый образ:** `postgres:18-alpine`

---

## 2. Что делает

Сервис `db` представляет собой реляционную систему управления базами данных PostgreSQL версии 18:
- Обеспечивает изолированное и надежное хранение всех данных микросервисов Tether (пользователи, отозванные токены, листы питания, приемы пищи, антропометрия, продукты, статьи базы знаний).
- Обрабатывает параллельные транзакции от сервисов `auth`, `diary` и `kb`.
- Сохраняет данные на диске хост-системы через постоянный том (volume) Docker `pgdata`, что предотвращает потерю данных при перезапуске или обновлении контейнеров.
- Регулярно проверяет свою готовность с помощью встроенного механизма проверки работоспособности (Healthcheck).

---

## 3. Особенности

### Как работает
- **Контейнеризация на Alpine Linux:** Используется легковесный образ `postgres:18-alpine`, что минимизирует занимаемое дисковое пространство и ускоряет запуск.
- **Постоянное хранилище (Volume):** Данные СУБД монтируются в Docker volume `pgdata` (`/var/lib/postgresql`). При выполнении команды `docker compose down` данные сохраняются. Полная очистка базы возможна только при явном указании флага удаления томов: `docker compose down -v`.
- **Healthcheck:** В манифесте `db/docker-compose.yml` настроена регулярная проверка доступности:
  ```yaml
  healthcheck:
    test: ["CMD-SHELL", "pg_isready -U $${POSTGRES_USER} -d $${POSTGRES_DB}"]
    interval: 5s
    timeout: 5s
    retries: 10
  ```
  Это позволяет зависимым сервисам ожидать полной инициализации СУБД перед началом работы.

### Параметры подключения
- **Хост внутри Docker-сети:** `db`
- **Хост с локального компьютера:** `localhost`
- **Порт:** `5432`
- **Имя базы данных:** `tether`
- **Пользователь:** `tether`
- **Пароль:** `P@ssw0rd`
- **Строка подключения SQLAlchemy:** `postgresql+psycopg://tether:P%40ssw0rd@db:5432/tether`

### С чем взаимодействует
- **Микросервис Auth (`pyth/auth`):** Таблицы `auth` (пользователи) и `revoked_tokens` (отозванные токены).
- **Микросервис Diary (`pyth/diary`):** Таблицы `diary_sheets`, `entries`, `bio`, `base_products`, `user_products`, `favorites`.
- **Микросервис KB (`pyth/kb`):** Таблица `kb_articles`.
- **Панель pgAdmin 4 (`pg`):** Сетевое управление и выполнение запросов через порт 5432.
