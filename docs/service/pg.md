# Сервис графического интерфейса БД PG (pgAdmin 4)

## 1. Где находится

- **Каталог:** `pg/`
- **Файл конфигурации:** `pg/docker-compose.yml`
- **Имя сервиса в Docker Compose:** `pgadmin4`
- **Имя контейнера:** `pg`
- **Порт веб-интерфейса:** `8080` (проброшен наружу `8080:80`)
- **Базовый образ:** `dpage/pgadmin4`
- **URL для доступа:** `http://localhost:8080`

---

## 2. Что делает

Сервис `pg` предоставляет полноценную графическую веб-панель управления базой данных PostgreSQL:
- Визуальный просмотр всех таблиц, связей, индексов и схем базы данных `tether`.
- Интерактивный редактор SQL-запросов (Query Tool) с подсветкой синтаксиса и автодополнением.
- Ручной просмотр и редактирование строк таблиц.
- Анализ производительности СУБД и просмотр активных сессий/транзакций.
- Экспорт и импорт данных, создание резервных копий (дампов).

---

## 3. Особенности

### Как работает
- **Веб-доступ через браузер:** Сервис запускается в отдельном контейнере и доступен по адресу `http://localhost:8080`.
- **Постоянное сохранение сессий:** Настройки подключений, история SQL-запросов и конфигурация сохраняются в постоянном Docker volume `pgadmindata` (`/var/lib/pgadmin`).

### Учетные данные для входа в веб-панель
- **Email:** `adm@mail.ru`
- **Пароль:** `P@ssw0rd`

### Подключение к базе данных Tether
После входа в веб-панель pgAdmin подключение к базе данных настраивается следующим образом:
1. Выбрать пункт **Add New Server** (или нажать правой кнопкой мыши по *Servers -> Register -> Server*).
2. Во вкладке **General**:
   - Поле *Name:* `Tether DB`
3. Во вкладке **Connection**:
   - Поле *Host name/address:* `db` *(имя контейнера СУБД во внутренней сети Docker)*
   - Поле *Port:* `5432`
   - Поле *Maintenance database:* `tether`
   - Поле *Username:* `tether`
   - Поле *Password:* `P@ssw0rd`
4. Нажать **Save**.

### С чем взаимодействует
- **Контейнер базы данных `db`:** Соединяется с СУБД PostgreSQL по внутренней сети Docker Compose на порту `5432`.
