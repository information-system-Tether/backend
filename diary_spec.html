Diary Service

Спецификация взаимодействия микросервиса дневника питания, КБЖУ, профиля здоровья и каталогов продуктов.

Swagger UI документация
http://localhost:8002/docs
Схема авторизации
Bearer JWT Token

Вводная информация:

Уровни активности (activity_level)
1 - сидячий образ жизни, минимум нагрузок
2 - лёгкая активность, прогулки 1-3 раза в неделю
3 - умеренная активность, спорт 3-5 раз в неделю
4 - высокая активность, тренировки 6-7 раз в неделю
5 - экстремальная активность, тяжёлый физический труд
Цели пользователя (target_goal)
1 - похудение (дефицит калорий)
2 - набор массы (профицит калорий)
3 - рекомпозиция (сжигание жира с сохранением мышц)
4 - удержание веса (баланс суточных калорий)
Категории продуктов (product_type)
meatfish (мясо/рыба), garnish (гарниры), vegetables (овощи), fruits (фрукты/ягоды), nuts (орехи), sweets&candies (сладости/конфеты), baking (выпечка), sauces&spices (соусы/специи), beverages (напитки), dairy (молочные продукты), grains (крупы/каши), oils (масла/жиры), soups (супы), fastfood (фастфуд), supplements (добавки/спортпит), other (прочее)
Расчёт воды и пересчёт порций
Для напитков (категория beverages) объём выпитой жидкости в литрах рассчитывается автоматически по формуле quantity_grams / 1000. Для прочих категорий вода равна 0.0.
Для разовых ручных записей КБЖУ пересчитываются под указанный вес порции.
Расчёты где?
Всё на бэкенде, соответственно и выводы с расчётов также передаются из него. В основном, это переменные total_(что-то там). Расчёты производятся в зависимости от данных в профиле здоровья (включая активность и цель).
Как эта хрень работает?
Принцип: юзер имеет один дневник; дневник имеет множество листов (поиск по датам для пользователя); в одном листе - записи Запись может быть трёх видов: базовая (продукт взят из системного списка, подгружаемого из бэкенда); пользовательская (юзер сам добавляет продукт и несколько раз его использует); одинарная (не привязан к какому-либо списку продуктов, нужен для единичного добавления). Записи, создаваемые пользователем, Список "Избранное" нужен для приоритизации поиска нужных и существующих продуктов.

POST /health/me
Bearer Auth

Создать профиль здоровья.

Требуется передать параметры тела, уровень активности и цель. Математический модуль автоматически вычисляет диапазон калорий, белки, жиры, углеводы, суточную норму воды и рекомендованное число шагов (если передано значение 0).

Параметры тела запроса (JSON)
ПолеТипОбязательностьОписание
genderstringОбязательно"m" (мужской) или "f" (женский)
ageintegerОбязательноВозраст от 12 до 125 лет
weightnumberОбязательноТекущий вес в кг (от 0 до 400.0)
heightnumberОбязательноРост в метрах (например 1.80)
activity_levelintegerОбязательноУровень активности от 1 до 5
target_goalintegerОбязательноЦель от 1 до 4
target_stepsintegerОпционально (по умолчанию 0)Цель шагов в день (0 - рассчитать автоматически)
Похудение (дефицит калорий)

{

  "weight": 85.0,
  "height": 1.8,
  "activity_level": 2,
  "target_goal": 1,
  "target_steps": 0
}

{

  "weight": 70.0,
  "height": 1.78,
  "activity_level": 3,

  "age": 28,
  "weight": 60.0,
  "height": 1.68,
  "activity_level": 2,
  "target_goal": 4,
  "target_steps": 0
}

proteinsnumberОбязательноБелки на 100 г (не менее 0)
fatsnumberОбязательноЖиры на 100 г (не менее 0)
carbsnumberОбязательноУглеводы на 100 г (не менее 0)

Предусмотрено три варианта добавления записи в зависимости от источника продукта:

Ручной ввод разового продукта или блюда

{
  "name": "Филе минтая в панировке Экспродов",
  "description": "Рыбные котлетки в кляре",
  "product_type": "meatfish",

  "fats": 16,
  "proteins": 6.5,
  "carbs": 5,
  "quantity_grams": 200

{

  "quantity_grams": 150
}
Свой продукт из каталога

Bearer Auth

Обновить запись в дневнике.

Обновление записи дневника по её идентификатору ide.

Для продуктов из каталога (базовых или своих) достаточно передать новое значение quantity_grams - КБЖУ и объём воды автоматически пересчитаются пропорционально новому весу.

Для произвольной ручной записи можно обновить название, граммы и параметры КБЖУ.

Изменение веса порции
Для продукта из каталога передаётся только новый вес порции:
{
  "quantity_grams": 150
}
Редактирование ручной записи
Изменение названия и значений КБЖУ для произвольной записи:
{
  "title": "Филе минтая в кляре",
  "quantity_grams": 150,
  "calories": 195,
  "proteins": 9.75,
  "fats": 24,
  "carbs": 7.5
}
